# Iris Flower Classification

## 📌 Project Overview
This project focuses on classifying Iris flowers using machine learning. The aim is to predict the species of an Iris flower based on its measurements.

## 🎯 Project Objective
To understand and implement a machine learning classification problem using the Iris flower dataset.

## 🛠️ Technologies Used
- Python
- Google Colab / Jupyter Notebook
- Machine Learning
- Data Analysis and Visualization

## 📊 Dataset
The Iris dataset contains flower measurements that can be used to classify three species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## ⚙️ Project Workflow
1. Load the dataset.
2. Explore and understand the data.
3. Prepare the data for classification.
4. Train a classification model.
5. Evaluate the model's performance.

## 📁 Project File
`OASIS_INFOBYTE_Iris_Flower_Classification.ipynb`

## ▶️ How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the cells in sequence.
3. Review the model results and visualizations.
